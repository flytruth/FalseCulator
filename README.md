🤔 What is FalseCulator?

FalseCulator is a calculator built in Python with Tkinter that has one simple job: to calculate. It does not do that job.

Instead, it:

    🕵️ Goes nearly invisible (alpha = 0.1) so you can barely see it — like it's ashamed of itself

    🧠 Asks you philosophical questions in the console before it will even let you use it

    🔢 Rejects your correct math if you type it as a string instead of an int (it's very strict)

    🟢 Has green buttons that look functional but are decorative only

    🖨️ Prints <built-in function truediv> to your terminal when you click "Calculate" — instantly, before you even click it, actually

    📦 Contains a big empty text box for reasons nobody fully understands

This is not a bug. This is a lifestyle.
🚀 Installation
bash

# Step 1: Have Python installed (probably)
# Step 2: Have Tkinter installed (you probably do)
python falseculator.py

That's it. There's no requirements.txt. There's no setup.py. There is only chaos.
📖 How to Use

    Run the script

    A window appears. Squint. It's there. Barely. (Opacity: 0.1)

    Look at the console. It's asking:
    text

    Do you really want to use calculatro? Enter 123 + 1:

    Type 124. If you type "124" (as a string), you will be told "Nope." The program will still run anyway. It's not a real gatekeeper.

    Click buttons. Watch nothing happen. Marvel at the emptiness.

    Click "Calculate." Observe the console politely inform you that operator is, in fact, a module.

    Use the big text box at the bottom to reflect on your life choices.
